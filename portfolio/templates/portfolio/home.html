01. About

Who I Am

I'm a Senior Full-Stack Software Engineer with deep roots in backend engineering and systems programming. I completed the ALX Africa Software Engineering Program — going from writing UNIX shells in C to shipping production Django CMS platforms.

My backend is anchored in Python, Django, FastAPI, and PostgreSQL — with real production deployments on Docker + Nginx. On the frontend I'm fluent in React, Vue, Nuxt, Next.js, and Angular. I'm competent in Java + Spring Boot and have written production-grade systems code in C.

Currently building an Audio Business ERP + POS system and an anonymous intelligence platform. I actively study system design and write about engineering on Medium and Dev.to.
